## Shipped
| Track | Feature | New platform feature | Status |
|---|---|---|---|
| Databricks | Basket and aisle allergens (PR #48) | `collect_union` aggregate (Databricks SQL 2026.35) | built |
| Google Cloud | Store-day KPIs (PR #49) | Multi-level aggregation (Preview) | built |

- **Databricks:** 18 products with Open Food Facts-style allergen arrays in 5 aisles, 12 baskets in two stores.
  One read-only query rolls the arrays up per basket and per aisle with `collect_union`, next to the long-hand
  `array_distinct(flatten(collect_list(...)))`, and flags nut baskets with `arrays_overlap`. Local: Python set
  unions, cross-checked in the test with DuckDB `list_distinct(flatten(list(...)))`. **2 of 12** baskets
  allergen-free, **5** with nuts, gluten in **8**, **3 of 5** aisles nut-free. The cloud check fails on any group
  whose allergen set differs or where `collect_union` disagrees with the long-hand version.

- **Google Cloud:** 3 stores x 14 days, 208 baskets, 458 lines, per-store shelf prices in cents. One `GROUP BY
  store` returns `AVG(SUM(revenue) GROUP BY sale_date)`, `MAX(SUM(...) GROUP BY sale_date)`, the weekend-day average
  via an inner `HAVING is_weekend`, basket value and size via `GROUP BY basket_id`, and
  `AVG(ANY_VALUE(shelf_price) GROUP BY sku)`. Local: DuckDB with a CTE per inner level (and pure Python in the
  test). Riverside Fresh's weekend days run **+68%** over its average day, Southgate's **−6%**; average baskets
  $11.86 / $14.06 / $14.79; a plain `AVG(shelf_price)` over the join is **77–133 cents** too low. The cloud check
  fails on a missing store or any KPI more than 0.01 cents off.
