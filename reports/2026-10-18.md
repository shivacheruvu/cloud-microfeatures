- **Databricks:** 87 shelf-tag price changes for 11 SKUs in 3 stores and per-store sales in 4 aisles. One read-only
  query keeps the newest tag per store and SKU with `QUALIFY ROW_NUMBER() ... = 1` (the `COUNT(*)` and `LAG` windows
  in the same SELECT still see every change) and the top 2 sellers per aisle with `QUALIFY RANK() OVER (... ORDER BY
  SUM(qty) DESC) <= 2`. Local: plain Python, and the test runs the exact query in DuckDB. **33** current prices,
  **12 of 24** latest changes were cuts, P07 differs by **120 cents** across stores, and the produce tie at rank 2 is
  kept. Day 14 is the last trial day; the query is serverless and read-only, so it carries over to Free Edition.

- **Google Cloud:** 3 stores x 28 days of ice cream revenue, high temperature, promotion depth and foot traffic,
  inlined into one query that calls `ML.CORRELATION` twice (PEARSON and SPEARMAN) with `dimension_cols => ['store']`:
  24 rows (2 methods x 3 stores + overall x 3 columns). Local: pure Python, cross-checked with numpy in the test; the
  data is tie-free so Spearman needs no tie rule. Lakeside follows the weather (**r = 0.96**), Downtown the
  promotion (**0.96**), Campus foot traffic (**0.91**); pooled, temperature shows only **0.48**.
