- **Google Cloud:** `job315.py` uses four Python 3.15 features: comprehension unpacking (`{**layer for …}` resolves
  chain → region → store shelf prices, `[*feed for …]` flattens promo feeds), built-in `frozendict` (duplicate promo
  rules with a different key order collapse, 8 → 6), `lazy import statistics`, and UTF-8 mode by default (receipt
  with Jalapeño / Crème fraîche written without `encoding=`). 10 baskets at 4 stores: gross $169.06, promo $17.18, net
  $151.88. Must equal a plain Python 3.12 reference and report Python 3.15.
- **Databricks:** per-store `tuple_sketch_agg_double(customer_id, spend)` and one `theta_sketch_agg` of e-mailed
  customers. Intersection = reached buyers and their spend, difference = missed buyers, union = everyone touched;
  chain-wide after `tuple_union_agg_double`. The e-mail reached 189 of 569 buyers ($15,193.27 of $47,001.40) and
  missed 380; 630 touched. Local pyspark 4.3 equals the plain-Python set arithmetic (exact at this size).
