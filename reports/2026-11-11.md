## Shipped
| Track | Feature | New platform feature | Status |
|---|---|---|---|
| Google Cloud | Count every picked item in nested tote manifests (PR #136) | `JSON_FLATTEN` (GA) | **ran** |
| Databricks | Night restock pick list with a UDF inside `range()` (this PR) | Scalar UDFs as TVF arguments (2026.32) | built; cloud expected to warn (account inactive) |

- **Google Cloud:** eight synthetic online orders pack items at depths 1 to 4 (tote → bag → item, an item straight in
  a tote, a bag inside a bag, an express order with a flat list). `JSON_FLATTEN(JSON_QUERY(doc, '$.totes'))` finds all
  **33 items / 68 units / $418.62**; the old fixed-depth `JSON_QUERY_ARRAY` unnest **silently drops 8 items ($108.96)**
  from four orders. Substitutes (an array inside each item object) are not counted as extra items.
- **Databricks:** a temporary SQL UDF `cases_to_pick(on_hand, par, pack)` goes straight into
  `range(1, cases_to_pick(...) + 1)` to make one row per case: 8 shelf lines → **15 cases, 162 units** (at-par and
  overstocked lines get none). Open-source Spark 4.3 refuses the same query with `NON_FOLDABLE_ARGUMENT` (checked
  locally); the old `explode(sequence(...))` way gives the same list on local pyspark. The serverless job runs both and
  requires each to equal the reference; a refusal of the new syntax is an error.
