## What the first cloud runs taught us (fixed forward the same day)
- `bq query "<sql>"` reads a SQL comment starting with `--` as a flag: pass SQL on stdin.
- BigQuery's `maximum_bytes_billed` must be at least 10 MiB (its per-query minimum); use 20 MiB for tiny queries.
- With keyless auth, `bq` prints a `--scopes` warning; parse JSON from the first `[`.
- Run logs aren't readable from Claude sessions, so cloud scripts report errors and results as `::error` / `::notice`
  annotations (read them with `gh api repos/OWNER/REPO/check-runs/ID/annotations`), never printing project IDs.
