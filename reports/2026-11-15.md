- **Google Cloud:** `supplier_sheet.py` writes a one-page supplier price sheet as a PDF byte for byte (Helvetica
  text and a ruled grid: 6 SKUs, case packs, case costs totalling $160.75), so the answer key is exactly what's
  printed. `cloud.sh` uploads it to a short-lived bucket and one query runs `AI.PARSE_DOCUMENT(..., layout-v1)`; the
  run must find the title, all 6 SKUs and all 6 case costs with no errors, and reports block types, whether a table
  came back and how many SKU rows are rebuilt with the right cost.
- **Databricks:** a serverless job builds `shelf_cost_v` (same six SKUs) with a comment, two governed tags and a
  `SELECT` grant to `account users`, replaces it with a wider definition (units, unit cost) that says nothing about
  governance, and compares `information_schema` before and after: comment, tags and grant must be kept, rows equal
  the reference (cheapest unit HF-3001 at $2.49). Locally, open-source Spark 4.3 returns the same rows but its replace
  drops the comment and properties: the behaviour the release removes for Unity Catalog views.
