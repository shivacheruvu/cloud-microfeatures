- **Databricks:** 3 stores x 40 baskets through one `psdf.groupby("store")["basket"].describe()`. Each store's row sets
  a coupon threshold (Q3: downtown $48.33, suburb $95.89, campus $26.03) and a bulk fence (Q3 + 1.5 IQR): 30 coupons,
  3 catering / party orders flagged. Finding: pandas-on-Spark quartiles are observed baskets (percentile_approx,
  nearest rank), not interpolated like pandas (downtown Q3 $48.33 vs $48.40). The local test runs the real call on
  pyspark 4.3 and it matches the nearest-rank reference exactly.
- **Google Cloud:** one view over a 24-row price table filters by `SECURE_CONTEXT('store_id')` and shows unit cost and
  margin only for `SECURE_CONTEXT('role') = 'buyer'`. Five callers run identical SQL, passing only the secure context:
  each store sees its own 8 prices, the north buyer sees costs (avg margin 36.2%), an unknown store sees 0 rows. The
  local test runs the view SQL on DuckDB with the context substituted. The cloud run also checks the documented
  failures (no context, missing key, top-level call).
